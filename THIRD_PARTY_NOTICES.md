# Third-party notices

GaugeBase includes open-source libraries distributed under their respective licenses. The authoritative dependency set and versions are recorded in `package-lock.json`.

Major runtime components include React, Vinext, Dexie, jsPDF, QRCode, JsBarcode, Papa Parse, Lucide, Noble Hashes, Base UI, shadcn components, and Tailwind CSS. Geist and Geist Mono are loaded through the framework’s font integration.

This notice does not replace dependency license texts. Run `npm ls --all` and an SBOM/license scanner for deployment-specific review.
